### 2. Conglomerate Test Results (SIGNIFICANTLY EXPANDED)
**Location**: Replaces lines 239-251

**New Content Includes**:
- **Watson (1956) Test Methodology**: Detailed explanation of statistical test
  - Compares resultant vector R to Ro (critical value)
  - Pass criteria: R < Ro_95, K=1-3, A95 > 10°, R << n
  - Fail criteria: R > Ro_95 (systematic clustering)

**Sites PASSING Test (3 sites - confirmed ejecta)**:
1. **NWF-C/NWF24-C** (8 block samples)
   - N=8, R=3.37, Ro_95=4.48 → PASS (R < Ro_95)
   - Excellent random scatter, K=1.5, alpha95=74.5°
   - Textbook passing behavior

2. **PKQ-A/PKQ24-A** (4 boulders, 10 cores)
   - N=4, R=2.80, Ro_95=3.18 → PASS (R < Ro_95)  
   - Close to failure but passes
   - Boulders 3&4 share direction, Boulder 2 distinct
   - Some complexity but overall random

3. **PKS-F/PKS24-F** (10 samples)
   - N=10, R=4.72, Ro_95=5.03 → PASS (R < Ro_95)
   - Excellent random distribution, K=1.7, alpha95=56.0°
   - Only demagnetized to 70°C but already shows clear pattern

**Site FAILING Test (1 site - likely in-situ weathered flow)**:
- **PKS-G/PKS24-HF** (8 block samples)
  - N=8, R=6.68, Ro_95=4.48, Ro_99=5.26 → FAIL (R > Ro_99)
  - Systematic clustering in SE quadrant, K=5.3, alpha95=26.5°
  - Likely represents weathered in-situ flow, not ejecta
  - Important negative result showing method discrimination
