## 🔧 METHODOLOGY DETAILS

### Watson (1956) Conglomerate Test
**Pass Criteria** (Random = Ejecta):
- R < Ro_95 ✓
- Low K (1-3) ✓
- High Alpha95 (>10°) ✓
- R << n ✓

**Fail Criteria** (Clustered = In-Situ):
- R > Ro_95 ✗
- Higher K (>3) ✗
- Systematic directions ✗

### Thermal Demagnetization
- Progressive heating in 30-50°C steps
- Up to 580°C (magnetite Curie point)
- Most intensity lost by ~450°C (maghemite transformation)
- Principal Component Analysis (PCA) for ChRM isolation
- MAD <15° for reliable directions

### Magnetic Characterization
- VSM hysteresis loops for domain states
- MPMS low-temperature measurements
- FORC analysis for magnetic interactions
- Weathered vs. fresh sample comparisons

## 💡 PRACTICAL INSIGHTS

### What Works Well
✓ Conglomerate tests reliably distinguish ejecta from in-situ flows  
✓ Polarity matching validates ages when correctly assigned  
✓ Fisher statistics quantify directional scatter objectively  
✓ Watson test provides clear pass/fail criteria  
✓ Combined paleomag approach powerful for impact studies  

### Challenges Identified
⚠ Tropical weathering complicates field identification  
⚠ Maghemite thermal instability limits heating protocols  
⚠ Some radiometric ages require reassessment  
⚠ Lightning strikes can affect isolated boulders  
⚠ Careful site selection and sampling critical  

### Recommendations
1. **Redating**: PKS-K and PKS-J need new ⁴⁰Ar/³⁹Ar ages
2. **More demag**: PKS-I, PKS-K to higher temperatures
3. **PKS-H study**: Investigate potential self-reversal in HA1
4. **Expanded sampling**: Based on revised ejecta extent
5. **Lightning tests**: IRM acquisition for suspicious samples
