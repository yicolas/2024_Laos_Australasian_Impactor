## WATSON TEST CRITERIA

### How to Interpret Results

**PASS (Random = Ejecta)**
- R < Ro_95 ✓
- Low K (1-3) ✓
- High Alpha95 (>10°) ✓
- R << n ✓
- Scattered equal-area plot ✓

**FAIL (Clustered = In-Situ)**
- R > Ro_95 ✗
- Higher K (>3) ✗
- Lower Alpha95 (<10°) ✗
- R approaches n ✗
- Systematic clustering ✗

## KEY STATISTICS THRESHOLDS

### Well-Constrained Directions
- **Alpha95 < 10°** = tight clustering
- **K > 20** = good precision
- **MAD < 15°** = reliable PCA fit

### Random Distribution (Ejecta)
- **Alpha95 > 50°** = scattered
- **K < 5** = poor precision (good for ejecta!)
- **R << n** = resultant much less than sample size

### Thermal Demagnetization
- **~450°C**: Most intensity lost (maghemite transformation)
- **~580°C**: Curie temperature (magnetite)
- Progressive unblocking = primary TRM
